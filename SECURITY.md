# Security policy

RVC Dataset Studio is a static site: there is no server-side code and no user data leaves the browser. Security issues are still possible — for example a way to bypass the Content-Security-Policy, to make the page send data somewhere, or to read another site's data.

**Please do not open a public issue for security problems.** Use GitHub's private vulnerability reporting (“Security” tab → “Report a vulnerability”) on this repository.

Include what you found, how to reproduce it and which browser you used. You will get an answer as soon as a maintainer can look at it; fixes are released on the main branch and deployed immediately.
